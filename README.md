# AI-Guides-Life

用 AI 辅助长期了解、综合建议、周期规划、执行与复盘的通用方法论库。

本仓库面向任何希望改善生活组织方式的人。它提供框架、操作步骤、提示词和空白模板；读者在仓库之外的独立私有空间完成个性化配置。

> **最高优先级：仓库仅保存可公开复用的方法论，不得包含任何人的个人信息。此规则在仓库为 private 时同样生效。**

## 如何使用本仓库

本仓库是一套可阅读、复制和自行定制的方法，不需要先运行程序或接入设备。可以直接浏览文档，或下载、克隆后使用；Python 检查脚本只用于仓库维护，不是开始使用的前提。

### 1. 选择一个领域，明确一个问题

先阅读[隐私规则](docs/privacy.md)和[快速开始](docs/quick-start.md)，再从下方九大领域中选择当前要改善的事项。不必同时启用全部领域，也不需要一次提供全部生活资料。

### 2. 在仓库之外建立独立私有空间

将[个性化配置模板](templates/personal-setup.md)及所选领域需要的材料复制过去，只在该私有空间填写。真实计划、身体与设备记录、饮食、书单、行程、联系人、录音和复盘都不得写入本仓库或其子目录；即使目录被 Git 忽略也不例外。直接使用一个 fork 同样不能替代独立私有空间。

### 3. 把指南和提示词交给所选 AI 工具

复制对应领域指南中的提示词，或使用[通用工作流](prompts/core.md)，再提供完成当前问题所需的最少信息。也可以不使用 AI，手动按指南执行。需要持续观察时，先确定必要字段、数据来源、观察范围和复查条件；没有的信息标记“待确认”，不让 AI 补造。

第一次对话可使用下面的通用开场，在私有空间替换占位符：

```text
请按照本仓库的方法，帮助我处理一个生活领域的问题。
我会提供所选领域的指南和通用提示词。

所选领域：<待填写>
希望改善的问题：<待填写>
已知约束与已有记录概况：<只提供必要信息，未知则说明>

先说明还缺什么，以及哪些部分现在就能处理。
如需持续记录，请先给最低必要字段和复查条件。
区分事实、估计、假设和未知，输出主方案与缩减方案。
本次只建议和草拟，不创建提醒，不连接设备，不发送或购买。
所有个人内容仅在这个独立私有空间处理，不回写方法论仓库。
```

### 4. 从记录形成建议，再安排到月、周、日

在私有空间积累或整理必要记录，使用[阶段总结](templates/period-review.md)区分实际情况、估计和缺口；信息不足时先做有限建议。由使用者确认取舍，再用[月计划](templates/monthly-plan.md)、[周计划](templates/weekly-plan.md)和[日计划](templates/daily-plan.md)落实。不需要设备也可以开始，真实设备数据不随仓库保存。

出行、旅游或见面出现时，可先用[活动评估](templates/activity-review.md)比较参加、缩短、改期或放弃，再纳入日程。

### 5. 执行、反馈与复盘

记录实际完成和主要阻碍，用[周复盘](templates/weekly-review.md)调整安排；每日反馈可以修正周计划，周复盘可以修正月方向。没有反馈不能视为完成，记录负担过高时减少字段或频率。

### 6. 按需接入工具或贡献通用改进

日历、提醒、穿戴读取、录音、发送和购买等都不会因阅读本仓库而自动启用。确有需要时，在私有环境按[自动化约定](docs/automation.md)确认权限、范围、费用和撤销方式。健康相关总结保留[证据与专业判断边界](docs/evidence.md)。

如需贡献，只提交重新编写的通用方法、空白模板或从零构造的虚构示例，按[贡献指南](CONTRIBUTING.md)检查；不要上传个人使用记录、原始聊天或填写后的模板。

## 九大生活领域

| 领域 | 主要问题 | 方法论入口 |
| --- | --- | --- |
| 日常作息 | 如何统筹月、周、日与全部领域，并按实际反馈调整 | [作息指南](domains/01-daily-routine/README.md) |
| 睡眠 | 如何结合持续设备记录与体验，形成阶段总结和建议 | [睡眠指南](domains/02-sleep/README.md) |
| 饮食 | 如何从粗略记录估计摄入、识别结构缺项并持续复盘 | [饮食指南](domains/03-nutrition/README.md) |
| 喝水 | 如何记录每日大致饮用量并降低习惯执行的阻力 | [喝水指南](domains/04-hydration/README.md) |
| 健身 | 如何结合情况、训练与设备记录，给出分类型建议和安排 | [健身指南](domains/05-fitness/README.md) |
| 通勤 | 如何了解实际成本、优化方式与时长，并选择合适的时间用途 | [通勤指南](domains/06-commute/README.md) |
| 读书 | 如何结合历史与目标，建议书籍、阅读时长和方法 | [读书指南](domains/07-reading/README.md) |
| 出行、旅游 | 如何评估是否参加、优化行程与时间使用并复盘 | [出行指南](domains/08-travel/README.md) |
| 交友见面 | 如何评估活动、控制负担、协调安排与选择合意记录 | [见面指南](domains/09-social/README.md) |

日常作息是统筹层，连接月、周、日及其他八个领域；各领域在私有空间积累必要记录后形成阶段建议。出行旅游与见面按事件触发，先评估是否参加和如何调整，再安排与复盘。所有真实记录和设备数据仍在仓库之外。

## 仓库结构

```text
docs/        通用原则、隐私、协调、自动化与建设路线
domains/     九个领域的操作指南
prompts/     可复制到不同 AI 工具的提示词
templates/   仅含占位符的空白模板
examples/    明确标记的纯虚构方法演示
scripts/     文档结构、链接与常见敏感信息检查
.github/     自动检查配置
```

## 维护与检查

使用 Python 3.10 或更新版本，无需第三方依赖：

```sh
python3 scripts/check_repository.py
```

检查涵盖结构、站内链接、文件边界及若干常见敏感信息模式，不能替代人工隐私审查。详细规则见[贡献指南](CONTRIBUTING.md)。后续如转为 public，需另行审查完整 Git 历史；当前框架不代表已经连接日历、健康设备或任何个人账号。

本项目未指定开源许可证。未来是否公开、采用何种许可证，由维护者另行决定；仓库可访问性与内容再分发授权应分别处理。
