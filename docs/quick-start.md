# 快速开始

目标是完成一个可以重复的小循环，先观察实际负担，再扩展领域。

## 第一步：选择一个问题

从九个领域选一个当前希望改善的问题，例如“计划被打断后难以恢复”。将它改写为可观察结果，例如“发生中断时，能选出一个仍可完成的动作”。

这一过程在仓库外进行，不需要给本仓库提供任何个人背景。

## 第二步：建立私有工作空间

在本仓库之外新建独立私有空间，按需要复制：

- [个性化配置模板](../templates/personal-setup.md)。
- 对应领域的指南和提示词。
- [日计划模板](../templates/daily-plan.md)与[周复盘模板](../templates/weekly-review.md)。

只填写完成当前问题所需的字段。空缺信息保留“待确认”，不必一次性录入全部生活资料。

## 第三步：让 AI 给出可选方案

使用[通用提示词](../prompts/core.md)，要求 AI：

1. 复述目标与硬约束。
2. 列出未知项和需要核实的信息。
3. 给一个主方案、一个缩减方案和适用条件。
4. 为每个动作说明触发条件、完成标准与中断后的恢复方法。
5. 仅输出建议；外部动作另行确认。

## 第四步：确认与执行

由使用者选定可接受的方案。每次动作只记录“计划、是否实际完成、阻碍”所需信息；没有记录时不能被 AI 认定为已完成。

如果记录本身比动作更费力，先减少记录字段或降低提醒频率。

## 第五步：复盘一个变化

比较预期与实际，只选择一个需要调整的变量，例如提醒位置或动作复杂度。不要同时增加多个习惯、设备和指标。

能低负担地持续执行后，再参考[跨领域协调](cross-domain.md)连接其他领域。当前仓库提供操作框架，不会自动创建任何提醒或连接外部系统。
