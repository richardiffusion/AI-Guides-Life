# 长期了解、阶段建议与持续复盘

本方法在仓库之外的私有空间运行：按任务了解必要情况，积累可用记录，再生成分领域与跨领域建议。仓库仅定义方法、字段和空白模板，不接收原始数据、真实总结或填写后的配置。

## 两类循环

- 持续观察型：睡眠、饮食、喝水、健身、通勤与读书。使用已有历史或新记录建立初步认识，按数据质量逐步具体化建议。
- 事件触发型：出行旅游与交友见面。出现候选活动时评估，执行后复盘，再反馈到周期安排。
- 统筹层：日常作息整合全部领域，以月、周、日三个尺度协调，同时接收每日实际情况对周、月安排的修正。

各领域可以并行启动，也可以先选重点；没有完成所有领域的数据收集，不妨碍先整理已知约束和低风险行动。

## 从必要信息到可调整认识

1. 明确当前目标、已有承诺、可用资源、习惯与已知限制。
2. 按领域确定最低记录字段、可选扩展、观察周期与复查条件。
3. 在私有空间检查来源、覆盖、漏记、重复和估计成分。
4. 输出“观察到了什么、尚不能判断什么、建议如何行动”。
5. 经使用者选择后安排到月、周、日；执行反馈不能由计划反推。
6. 周期复盘时保留原始记录与修正关系，更新当前认识，不把旧推论永久当成个人特征。

“充分了解”指足以支持当前建议的必要信息，不要求收集完整病史、通讯录、所有生活记录或持续录音。每个必要字段都应能说明用途。

## 观察周期和建议成熟度

观察周期由领域问题、记录负担、日常变化和来源质量共同确定，起止与复查条件均为待确认。没有统一的“记录若干天即可诊断或精准推荐”门槛。

| 阶段 | 可输出 | 不能默认输出 |
| --- | --- | --- |
| 初始信息不足 | 缺口、记录方案、已知约束内的可行选择 | 精确个人结论 |
| 有部分记录 | 带范围的阶段观察、暂定建议、继续观察项 | 完整习惯或长期因果结论 |
| 覆盖多个相关情境 | 分情境比较、周期安排、可检查的调整 | 将相关变化认定为因果 |
| 持续反馈 | 对当前建议保留、修订或停止 | 永久不变的个人标签 |

不因“还没积累够数据”拖延必要的安全判断或专业支持。

## 每条记录的共用字段

| 字段 | 定义与处理 |
| --- | --- |
| 所属领域与事件代号 | 在私有空间关联，避免同一事件重复录入 |
| 实际发生时间 | 区分发生时间与补记时间；明确时区和跨日规则 |
| 记录值与单位 | 保留原始描述、原单位和换算规则 |
| 来源 | 手动自报、设备估计、包装标签、数据库或 AI 推断 |
| 证据类型 | 已报告事实、测量、估计、计划或未知 |
| 估计条件 | 份量、算法、匹配条目等假设与不确定性 |
| 完整性 | 完整、部分、漏记、不适用或未知；漏记不填零 |
| 覆盖与去重 | 有效记录范围、缺失范围、来源重叠和取舍 |
| 修正 | 指向原记录，说明改变了什么；更新汇总，避免重复累计 |
| 用途与权限 | 当前决策所需范围、保留规则及可撤销访问 |

以上是数据定义，不是已实现的数据系统。

## 穿戴设备与手动反馈

优先复用使用者已有、获授权的可用设备，不要求为方法论购买设备。Apple Watch 等可提供睡眠、活动或训练相关估计，具体能力按型号、地区与软件核实。

在私有空间记录设备与软件版本、佩戴覆盖、充电缺口、训练是否手动启动和时间归属。换设备或算法后标记比较边界；不要将多设备重复记录相加。缺少设备时仍可用手动记录，但输出精度与可用结论需相应降低。

## 阶段总结必须包含什么

使用[阶段总结模板](../templates/period-review.md)，输出：

1. 目标、观察范围、实际覆盖和数据限制。
2. 可支持的现状与变化；原始事实和派生估计分开。
3. 尚未记录与确实未发生的事项分开。
4. 分领域建议、跨领域冲突和替代选项。
5. 每条建议的理由、依赖、预期作用、负担和不确定性。
6. 可执行的下一步、需要专业判断的部分及复查条件。

睡眠、饮食和运动可联合形成非诊断的生活与健康相关总结，但不能把估计摄入减去设备消耗直接当作准确能量缺口，也不能从相关趋势诊断健康问题。相关依据见[健康与设备来源](health-sources.md)。
