# 共用系统方法

AI 的主要作用是根据必要的历史与持续反馈建立当前认识，整理约束、生成综合建议、减少重复操作和辅助复盘。目标设定、授权和重要取舍由使用者决定。

长期循环为：必要情况了解 → 历史或新记录 → 质量检查 → 阶段总结 → 综合建议 → 月周日安排 → 执行反馈 → 更新认识。观察周期与建议强度按数据覆盖和问题确定，详见[长期了解方法](longitudinal.md)。

日常作息负责统筹全部领域；睡眠、饮食、喝水、健身、通勤与读书可持续观察，出行旅游和见面按事件评估。真实数据、历史书单、设备记录与总结只保存在仓库之外。

## 一个完整循环

`明确目标 → 确认约束 → 选择最小动作 → 执行 → 记录事实 → 复盘 → 调整`

| 环节 | 核心问题 | 最小输出 |
| --- | --- | --- |
| 目标 | 希望什么结果发生变化 | 一个可观察结果 |
| 约束 | 什么不能被挤占或违反 | 硬约束与偏好分列 |
| 动作 | 下一个可实际执行的步骤是什么 | 触发、动作、完成标准 |
| 执行 | 谁执行，是否需要授权 | 责任人与授权状态 |
| 反馈 | 实际发生了什么 | 完成、未完成或未知 |
| 调整 | 哪个因素值得改变 | 一个变化与复查条件 |

## 计划的三个层次

- **方向**：希望改善的生活状态，不要求每天量化。
- **安排**：本周或当日可用资源与优先级。
- **动作**：下一次能开始、能结束的行为。

例如“多读书”是方向，“在选定空闲时段阅读”是安排，“打开选定材料并回忆上次内容”是动作。三个层次不能互相替代。

规划时间同时分为月、周、日：月确认方向与资源边界，周细化饮食、训练、阅读、睡眠、工作及事件安排，日落实动作并纳入喝水等高频流程。每日实际可反向修正周、月，不只有自上而下的分配。

## 约束优先级

先满足明确的安全限制、他人同意与已经承诺的事项，再协调资源、偏好和新增任务。具体约束由使用者在私有空间确认；AI 不得自行推断身体状况或替使用者牺牲休息。

## 事实状态

- 计划：已经提出，尚未执行。
- 已确认：使用者已选择或授权。
- 已完成：有使用者反馈或可靠执行证据。
- 未完成：明确知道没有完成。
- 未知：没有足够证据。

日历条目存在、提醒已发送、AI 写出总结，均不能直接视为行为已完成。

## 降低负担

每个领域先选择一个行动观察项和一个负担观察项，按需要增加。不要为了图表而收集无法影响决策的数据，也不比较不同人的完成率。

遇到连续中断时，先检查动作是否过大、环境是否不支持、触发是否不清楚。允许缩减、暂停和退出；补做不是默认恢复方式。
