# 出行与见面活动的取舍

对候选活动给出参加、调整、推迟或放弃的建议，并说明理由和不确定性。最终取舍及价值权重由使用者决定，评估对象是活动安排，不是人的价值。

## 先确认活动目的

使用者可以重视学习、工作、专业交流、关系维护、休闲体验、文化探索、陪伴或休息。没有学习或职业产出，不自动等于活动不值得。

只问足以改变判断的时间、专业或工作背景与近期安排，不要求透露具体雇主、身份或联系人。

## 活动前比较

| 维度 | 需要明确的内容 |
| --- | --- |
| 目的与意愿 | 为什么参加，是否真正愿意，是否已有承诺 |
| 时间全成本 | 准备、往返、等待、活动、收尾及恢复 |
| 金钱与精力 | 预算范围、取消成本、预期负担 |
| 预期价值 | 学习、工作、关系、休息、体验等，由使用者选定 |
| 近期适配 | 是否挤占已确认事项、睡眠或训练安排 |
| 替代选择 | 缩短、改期、换地点、线上交流或不参加 |
| 不确定性 | 预期能否实现，关键事实与第三方同意是否明确 |
| 可撤回性 | 取消、提前离开或调整的条件 |

不默认使用单一分数或“收益除以小时”计算性价比。需要评分时，先确认维度、权重和缺失值处理，不制造看似客观的精确结论。

## 建议输出

对每个选项列出适用条件、得到与放弃的内容、对月周日安排的影响，以及还需确认的事项。对已承诺活动，取消与改期需考虑责任和沟通，不能由 AI 擅自决定或执行。

## 执行后复盘

对照原先目的查看实际时间、费用、主观体验、关系或学习价值、恢复负担和后续事项。结果未知时保留未知；单次不佳不直接形成“以后永不参加”的规则。

根据重复出现的情况，可建议明确结束时间、降低频率、合并行程或减少准备成本。使用[活动评估模板](../templates/activity-review.md)。

## 见面记录的选择

优先考虑事后自述或简短纪要。确需录音时，本方法采用以下治理约定：

- 事前明确目的、必要性和适用的当地规则；参与者全部明确同意后才录制。该约定不等同于任何地区的合法性保证。
- 说明保存位置、访问人、保留期限及删除方式；拒绝或同意状态不明时不录音。
- 录音、转写、上传外部 AI、分享分别确认范围；同意录音不自动代表同意其他处理。
- 新参与者加入或用途变化时重新确认；可以暂停录制。
- 原音频与转写仅放在仓库外私有空间；人工检查转写和说话人归属，不能把模型推断当成对方原话。
- 不用录音推断人格、隐秘意图或给联系人评级。必要笔记同样受隐私边界约束。

这套约定是可选流程，不默认启用录音、监听或自动上传。关于组织会议录制的公开参考及地域限制见[来源说明](health-sources.md)。
