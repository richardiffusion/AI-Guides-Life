# 跨领域协调

跨领域规划的任务是发现资源冲突，给出取舍，让单个领域的优化能够服务整体生活。

## 先画依赖，再排动作

| 领域关系 | 常见冲突 | 协调方法 |
| --- | --- | --- |
| 通勤与作息 | 延误挤占后续安排 | 加入缓冲，提前确定可取消项 |
| 社交与睡眠 | 见面结束时间不确定 | 提前约定结束边界与返程备选 |
| 训练与饮食 | 训练前后缺少可行的用餐安排 | 一起考虑采购、备餐与出行条件 |
| 旅游与日常 | 环境改变，原有流程失效 | 选择旅行期间的最低可行版本 |
| 阅读与通勤 | 试图在不适合的交通情境阅读 | 根据交通方式选择安全可行的活动 |
| 饮水与通勤 | 取水、携带或如厕条件受限 | 调整准备与提醒位置，尊重个体限制 |

以上仅说明组织问题，不构成个性化健康建议。

## 冲突处理步骤

1. 列出明确承诺、不可移动事项和可调整事项。
2. 为地点切换、准备、收尾和恢复保留资源；不能只计算活动主体。
3. 当总量超过可用资源时，按使用者确认的优先级缩减。
4. 输出主方案与缩减方案，说明具体放弃了什么。
5. 新情况出现时，只重排受影响部分，不要求从头生成整天安排。

## 过载时的回退

- 取消可选扩展，保留已确认的必要事项。
- 将某些领域切换成最低版本，例如把完整阅读笔记改为一个待回顾问题。
- 无法兼容的事项明确标记为冲突，由使用者选择，不悄悄覆盖。
- 不将未完成事项全部累加到下一天。
- 涉及健康限制、第三方同意和费用时，按各自边界重新确认。
