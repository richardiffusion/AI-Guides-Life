# 信息核实与不确定性

本仓库首版提供组织和执行框架，不主张任何特定健康效果，也不预设适合所有人的作息、饮食、饮水或训练数值。

## 信息分层

| 类型 | 处理方法 |
| --- | --- |
| 使用者明确提供的事实 | 在私有空间标明来源，不补全未知部分 |
| 可以检验的外部事实 | 保存来源、核实日期、适用范围与结论 |
| 规划假设 | 明确写成“假设”，说明变化后如何调整 |
| 个人偏好或价值选择 | 交给使用者确认，不伪装成科学结论 |
| 未知项 | 标记“待确认”及对方案的影响 |

## 哪些内容需要核实

- 交通班次、场馆开放、价格、预约与取消规则。
- 出入境、证件、目的地与当地规则。
- 食品成分、过敏相关信息、设备测量解释和具体健康主张。
- 工具的数据处理、权限、成本和最新功能。
- 任何会影响费用、安全、时间承诺的时效信息。

优先查当前的官方或原始来源，保留可直接支持结论的链接。来源不足或相互冲突时，不生成确定结论；可以先输出不依赖该事实的准备工作。

## 健康领域边界

睡眠、饮食、喝水和健身指南用于组织信息与行为。涉及症状、诊断、药物、明确饮食限制或不适时，AI 不替代适当的专业判断，也不自行给出治疗或康复方案。

个体目标和限制由使用者在私有环境中确认。不得在没有依据时套用固定饮水量、能量摄入、睡眠时长或训练负荷。

## 引用规范

需要外部依据时，记录“具体主张、原始来源、核实日期、适用对象、已知限制、再核实触发条件”，使用[信息核实模板](../templates/source-check.md)。

事实核实与执行核实分开：查到一条有效路线不代表已经出发；找到一本书的介绍不代表读过原文。AI 总结应说明实际获得的材料范围。
