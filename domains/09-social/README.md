# 交友见面

帮助澄清见面目的、草拟邀约、协调时间地点，并尊重每个人的选择与边界。

## 私有输入

在仓库外按需提供：活动类型、可选时段、预算范围、交通便利条件和希望采用的表达风格。用“对方”“参与者”等代称即可，不上传通讯录、聊天记录或他人私人资料。

## 操作流程

1. 由使用者明确活动意图和希望传达的信息，不让 AI 推断对方心理。
2. 草拟简短邀约，给出可回应的选项与方便拒绝或改期的空间。
3. 在得到回应后协调安排，不把未回应或模糊表达视为同意。
4. 核实地点开放、交通与预约条件，确认费用分担和结束边界。
5. 发送、预约、共享位置或邀请其他人前，确认具体授权与必要同意。
6. 见面后按需要草拟感谢或后续联系，不自动评估、追踪或给人打分。

## 可复制提示词

> 请基于我明确表达的活动意图，草拟一段自然、简短的邀约，附可替换的时间和地点占位符。给对方拒绝、改期或不回应的空间，不推断情感、关系或心理，不使用施压和操纵表达。只生成草稿，不读取联系人、不发送消息；若后续执行，先核对对象、正文、时机和授权范围。

## 预期输出

邀约草稿、可选安排、待确认的同意、地点核实项和改期方案。真实称呼、联系人与消息填写在仓库外。

## 回退与复盘

对方拒绝或未回应时尊重边界，不默认追加催促。取消或改期需要对外沟通时，先准备草稿并遵守授权约定。

复盘表达是否清楚、安排是否方便、边界是否受到尊重。不对第三方建立画像，也不把实际对话转为公开案例。外部动作参考[自动化规则](../../docs/automation.md)。
