# 交友见面

根据必要的时间、专业工作背景与近期安排，评估见面的目的、价值、成本和频率，支持邀约、过程管理与复盘。最终选择由使用者决定，不给他人建立价值排名。

## 私有输入

仅在仓库外提供活动目的、参与者代号、可选时段、交通条件、预算和必要的近期约束。可说明与交流相关的专业主题，不要求真实身份、单位、通讯录或完整聊天。

## 记录字段

| 字段组 | 内容 |
| --- | --- |
| 活动目的 | 学习交流、工作协作、关系维护、陪伴、休闲等 |
| 约束与成本 | 准备、往返、等待、见面、收尾与恢复；费用和近期冲突 |
| 意愿与确认 | 邀约、回应、同意、拒绝、改期或未知，不推定他人态度 |
| 议题与边界 | 可选话题、希望了解的问题、结束时间、隐私和费用分担 |
| 候选与决定 | 参加、缩短、换方式、改期、降低频率或不参加；理由 |
| 实际反馈 | 经确认的发生情况、主观体验、收获、负担与后续事项 |
| 记录权限 | 是否记要或录音、分别授权的用途、私有保留与删除 |

不记录第三方画像，也不从沉默、措辞或录音推断隐秘意图。

## 操作流程

1. 确认活动意图、意愿、已有承诺和近期资源，明确价值由谁判断。
2. 比较是否参加及如何安排；评估学习和工作价值，同时尊重关系与休息等目的。
3. 提出控制时长、频率、准备或往返负担的选项，避免替使用者擅自取消。
4. 参加前草拟邀约与可选议题，确认结束和返程；外部发送或预约按授权执行。
5. 见面时以自然交流为主，记录方式按必要性与同意选择。
6. 事后对照预期复盘，整理经核对的要点和后续动作，调整周期安排与下次活动条件。

## 可选录音与转写

默认不录音，优先事后自述或简短纪要。确有必要时先核实适用规则，取得全体参与者事前明确同意，再分别确认录音、转写、外部 AI 上传及分享。不同意、状态不明或用途变化时不继续相应处理。

录音与转写仅存仓库外的私有空间，明确保留期限、访问和删除方式。转写可能出错，重要原话和说话人需核对；不得用它自动给人打分。完整方法见[活动评估与记录约定](../../docs/activity-evaluation.md)，该约定不是跨地区合法性保证。

## 可复制提示词

> 请结合我明确提供的目的、必要专业或工作背景、时间和近期安排，比较参加、缩短、改期、降低频率或不参加的选择。说明机会成本及学习、协作、关系或休息价值，不替我决定权重，不评价人的价值。选定后草拟邀约、议题和结束边界。复盘优先用事后自述；录音需先确认必要性、当地规则、全体同意及分用途授权，不自动录制、转写或上传。

## 预期输出

活动选择与理由、时长频率建议、邀约和议题草稿、可选的合意记录方式、实际复盘与后续安排。使用[活动评估模板](../../templates/activity-review.md)。

## 回退与复盘

拒绝或未回应时尊重边界，不自动追加催促。未录音不妨碍复盘，遗漏原话不能补造。对重复活动可按实际负担建议调整，但不能仅因没有学到东西就认定所有社交应取消。
