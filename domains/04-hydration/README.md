# 喝水

核心是用低负担方式记录每日大致饮用量，了解难以形成饮水习惯的阻碍，再决定环境调整、提醒与周期建议。

## 私有输入

只需当前任务相关的饮用习惯、容器、取水与携带条件、提醒接受程度及已明确的限制。不默认索取身体或医疗全量资料。

## 记录字段

| 字段 | 记录方式 | 是否必要 |
| --- | --- | --- |
| 日期与大致总量 | mL，或容器次数结合容量估计 | 最低记录 |
| 统计口径 | 白水或所有饮品；食品水分是否未统计 | 必须明确 |
| 容器容量 | 一次配置，变化时更新 | 用杯数估量时需要 |
| 来源与完整性 | 手动估计、容器计数等；全日或部分 | 最低记录 |
| 事件时间与饮品类型 | 逐次记录或少量场景记录 | 可选，不强制 |
| 阻碍 | 忘记、不喜欢、取水不便、携带或其他条件 | 按需选择 |
| 提醒反馈 | 有帮助、跳过、打扰或未反馈 | 启用提醒时 |
| 明确限制 | 已知且与当前任务相关的饮水边界 | 必要时 |

若已经由逐次记录汇总，不再加上同日自报总量。白水、饮料与食物水分不能在口径不明时直接合成“精确总水摄入”。

## 操作流程

1. 先选“每日总量估计”或“逐次汇总”，避免记录本身成为阻碍。
2. 记录一段时间的覆盖、量级与常见漏记，不用单日判断长期情况。
3. 了解不愿或难以喝水的具体原因，优先改善可获得性、容器与触发场景。
4. 需要通知时先确认频率、静默和暂停条件，不默认提高通知次数。
5. 结合通勤、训练与出行条件给出流程建议，目标须尊重个体明确限制。
6. 周期复盘是否更容易执行，再决定保留、调整或减少记录。

## 可复制提示词

> 请以每日大致饮用量为主要记录，先明确白水、其他饮品和食物水分的统计范围。根据一段时间记录及缺失情况，识别不爱喝水或难以取水的实际阻碍，提出低负担调整。不要预设适合所有人的固定饮水量，不要求强行补喝；提醒须先约定范围与暂停方式。

## 预期输出

每日粗略量与覆盖、阶段变化、阻碍解释、适用的准备或提醒建议，以及月周日安排中的衔接。

## 回退与复盘

逐次记录太累时退回每日粗估。没有取水条件时优先改善准备，不靠集中补量追赶打卡；已有专业限制或不适时先按相应边界处理。量的记录不是健康效果证明。
