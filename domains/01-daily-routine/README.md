# 日常作息

作为九大领域的统筹层，连接月、周、日安排：从大尺度分配资源，也从每日实际情况修正上层计划。工作与其他承诺作为必要约束纳入，不另建真实个人档案。

## 私有输入

只在仓库之外提供当前规划所需的目标、固定承诺、可用时间、精力与费用边界，以及各领域阶段总结。无需导入所有原始记录；未知信息保留待确认。

## 月、周、日如何衔接

| 尺度 | 规划内容 | 输出与反馈 |
| --- | --- | --- |
| 月 | 饮食、训练、阅读与睡眠方向；工作与重要事件；资源边界 | 月计划、领域重点、分周安排原则与观察问题 |
| 周 | 更具体的菜单采购、训练、阅读、睡眠与工作安排；通勤、见面与出行 | 周计划、依赖、准备恢复、可选项与缩减顺序 |
| 日 | 当日执行、喝水等高频动作、临时变化与实际反馈 | 日计划、必要提醒、事实状态与调整理由 |

月计划不提前锁死每天，周计划不填满所有空隙；每日变化可触发周重排，重复出现的冲突可触发月度方向调整。时长、频率和具体目标由使用者在私有空间确认。

## 操作流程

1. 先读各领域可用的阶段总结，区分事实、估计、建议和数据缺口。
2. 从月度目标识别需要持续投入的领域及明确承诺，保留休息与弹性。
3. 把目标分配到周，协调工作、训练、饮食准备、阅读、通勤和活动的资源。
4. 每日根据实际条件选择动作，纳入喝水等低负担记录与需要的提醒。
5. 将准备、移动、收尾和恢复计入资源，发现冲突时提出明确取舍。
6. 每日反馈影响周安排，周复盘影响月安排；保留改动依据，不自动累积任务债务。

## 记录字段

| 字段组 | 必要内容 | 何时更新 |
| --- | --- | --- |
| 方向与约束 | 目标、固定承诺、资源、偏好与优先级 | 周期开始或条件变化 |
| 计划层级 | 所属月周日、父目标、领域、动作与依赖 | 制定或重排时 |
| 时间全成本 | 主体、准备、移动、收尾与恢复 | 计划估计及事后修正 |
| 实际反馈 | 计划与实际、完成依据、中断、未知 | 事件后或日末 |
| 变更与冲突 | 哪项受影响、保留或取消什么、原因 | 发生变化时 |
| 统筹建议 | 依据、影响领域、待确认取舍与复查条件 | 周期复盘或重要事件 |

## 可复制提示词

> 请以月、周、日三个尺度统筹我提供的必要约束与各领域阶段总结。先说明数据覆盖和未知，再由月目标形成周安排、由本周实际形成日动作。计入准备、移动、恢复和弹性；加入工作及已确认事项，日内可纳入喝水。输出主方案、缩减方案及每日反馈如何修改周月计划。不要把估计当成事实，不替我决定价值权重；只草拟，不创建提醒或外部动作。

## 预期输出

月度方向、周安排、日动作、冲突与选择、跨领域建议及双向反馈规则。每项建议说明依据、资源、代价和复查条件。

## 回退与复盘

短期变化只重排受影响部分。反复无法执行时，检查月目标或周资源假设是否失真；允许降低任务量，不将全部未完成自动顺延。对需要专业判断的问题，不以“继续收集数据”代替必要处理。
