# 日常作息

把一天组织为可执行、可调整的安排，减少反复决定下一步的负担。

## 私有输入

仅在仓库外提供：已承诺事项、可用时段、准备与移动成本、不能被挤占的边界、希望保留的弹性。无需提供真实单位、地址或完整历史日历。

## 操作流程

1. 列出不可移动事项与可调整事项，标明来源和确认状态。
2. 为准备、移动、收尾与休息安排空间。
3. 选择当日重点，把每个重点拆成一个能开始的动作。
4. 按可用资源排入主方案；剩余任务放入候选，不强行塞满。
5. 提前定义缩减方案：发生延误时，保留什么、推迟什么。
6. 日末只核对实际完成与主要阻碍，不把计划自动当成完成。

## 可复制提示词

> 请依据我在私有对话中提供的事项与约束，先区分硬约束、偏好和未知项，再给出当日主方案与缩减方案。每个动作列出触发条件、准备成本、完成标准及中断后如何恢复。不要编造可用时间，不默认牺牲休息；发生冲突时列出需要我选择的取舍。只草拟安排，不创建日历或提醒。

## 预期输出

一张包含固定事项、重点动作、缓冲、待确认项和可取消项的计划。使用[日计划模板](../../templates/daily-plan.md)。

## 回退与复盘

临时插入任务时，只调整受影响部分；忙乱时选择一个仍可完成的重点，不将全部遗漏任务转为次日债务。

复盘关注：计划是否超出实际可用资源、准备成本是否被低估、缩减方案是否容易启用。调整一个因素后再观察。
