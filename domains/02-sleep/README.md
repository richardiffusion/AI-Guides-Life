# 睡眠

建立可观察的睡前、夜间和起床流程，帮助发现组织与环境上的阻碍。

本指南不设统一睡眠时长，也不根据设备评分诊断睡眠问题。

## 私有输入

在仓库外按需提供：希望调整的环节、已知时间限制、睡前活动类型、环境可调整项，以及已经明确的专业建议。无需上传原始健康导出或完整夜间数据。

## 操作流程

1. 将问题定位到一个环节：入睡准备、夜间环境或起床后的衔接。
2. 区分可调整行为与不可控因素，不把每次波动都归因于个人努力。
3. 为选定环节设计一个简单动作，例如提前准备次日用品。
4. 设定主流程与疲惫时的缩减流程。
5. 在私有空间用最少字段记录体验与阻碍，区分主观感受和设备估计。
6. 按约定周期复盘，不因单次设备分数频繁改方案。

## 可复制提示词

> 请帮我为一个睡眠相关环节设计低负担流程。先确认目标、可调整范围和未知项，再给出主流程、缩减流程及停止条件。区分我的体验、设备估计和你的假设，不诊断、不推荐药物，不预设统一睡眠时长。涉及持续困扰、明显日间影响或其他需要专业判断的情况，明确你的能力边界。

## 预期输出

选定环节、触发条件、具体动作、最低版本、观察项和复查条件。可用[单变量尝试模板](../../templates/experiment.md)。

## 回退与复盘

环境或行程变化时启用最低版本，不通过强行补偿来追赶记录。若出现明显不适或持续困扰，停止自行加码，让合适的专业支持参与判断。

观察执行负担、主观体验与环境变化；不要把相关性写成已证明的因果关系。
