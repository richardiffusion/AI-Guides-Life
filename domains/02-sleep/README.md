# 睡眠

在私有空间持续观察睡眠，优先利用已有穿戴设备的数据，再结合主观体验、作息和其他领域形成阶段建议及非诊断的健康相关总结。

## 私有输入

按任务提供作息约束、相关习惯、白天体验、已明确的限制，以及 Apple Watch 等设备的必要汇总。设备或导出未获授权时不读取；没有设备也可先手动记录，明确精度限制。

## 记录字段

| 字段组 | 内容与定义 | 来源与频率 |
| --- | --- | --- |
| 设备与覆盖 | 设备、软件、佩戴、充电、缺失和重叠记录 | 初始配置与每次变化 |
| 睡眠时间 | 上床、尝试入睡、估计入睡、醒来与离床；午睡单列 | 按日记录，注明自报或估计 |
| 睡眠指标 | 总睡眠、清醒或阶段等实际可得指标，保留原定义 | 设备支持时选用 |
| 主观反馈 | 醒后感受、白天困倦和功能影响 | 最低负担的每日反馈 |
| 情境 | 工作或休息日、出行、环境、相关饮食运动与压力线索 | 按需记录，不必全量追踪 |
| 已知边界 | 既有专业建议和需要支持的问题 | 仅在任务必要时提供 |

跨午夜归属、时区、午睡与主睡眠的汇总方式需先定义。阶段时间按来源保留，不混用不同算法口径；设备缺失不等于未睡。

## 操作流程

1. 确认要了解的问题和观察范围，覆盖相关的工作、休息或出行情境。
2. 核对佩戴覆盖、缺失与设备变化，区分自报和算法估计。
3. 比较一段时间的时点、规律、波动和主观体验，不用单晚分数代表整体。
4. 结合必要的训练、饮食、通勤与工作安排，提出可检查的关联线索，不断言因果。
5. 输出阶段睡眠总结，以及健康相关观察、未知和需要专业判断的部分。
6. 选择一项可调整流程放入月周日安排，继续记录并复盘。

观察周期不设统一临床门槛。Apple 的睡眠阶段是算法估计，不作为本方法诊断依据，见[设备来源](../../docs/health-sources.md)。

## 可复制提示词

> 请根据我在私有空间提供的一段时间睡眠记录、设备覆盖和主观反馈，先检查缺失、重复与算法口径，再总结规律、波动和不能判断的部分。结合已提供的作息、饮食和运动信息提出综合建议，分开事实、估计与关联假设。给出月周日可执行的调整与复查条件；不诊断、不推荐药物，不因设备单次分数自动加码。

## 预期输出

数据覆盖说明、睡眠现状与变化、相关情境、阶段建议、与其他领域的协调，以及进一步观察或专业支持的条件。使用[阶段总结模板](../../templates/period-review.md)。

## 回退与复盘

缺失较多时降低结论强度或调整记录方式，不补造数据。主观体验与设备冲突时并列保留并核对。持续困扰或明显日间影响不以更多手表数据替代适当专业判断。
