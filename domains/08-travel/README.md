# 出行、旅游

将目的、预算、交通、住宿、活动和突发变化整理成有核实依据的行程方案。

## 私有输入

在仓库外按需提供：出行目的、日期范围、预算、节奏、交通偏好和明确限制。证件号码、订单凭证、同行者身份、精确住宿位置不属于默认规划输入。

## 操作流程

1. 先明确想获得的体验与不能违反的约束。
2. 将确定事项、可选活动和待核实前提分开。
3. 核实适用的交通、营业、预约、费用、证件和当地规则。
4. 按地理关系、移动成本与休息需求组合活动，保留弹性。
5. 比较主行程与天气变化、延误、关闭情况下的备选。
6. 购买或预约前复核日期、对象、费用、取消条件和授权。
7. 临近出发和受变化影响时再次核实相关信息。

## 可复制提示词

> 请基于我的目的、范围和约束草拟旅行方案。先列前提与缺失信息；对交通、开放、预约、费用和适用规则提供当前官方来源及核实时间。无法核实的项目标记待确认，不生成虚构报价或可用名额。行程包含移动、准备、休息和备选。仅草拟，不订票、付款、联系商家或共享同行者信息。

## 预期输出

行程候选、费用构成与未知项、核实清单、准备清单、取消条件和备选触发点。使用[信息核实模板](../../templates/source-check.md)。

## 回退与复盘

关键前提未核实前，避免输出看似可直接购买的确定方案。计划变化时先核对订单状态和规则，不重复下单。

复盘预算结构、移动成本、实际负担和备选是否可用。经验要贡献回仓库时，重写为通用步骤，不保留真实日期、路线、住宿、票据或同行者信息。
