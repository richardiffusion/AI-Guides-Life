# 出行、旅游

出现候选出行或旅游时，评估其时间、精力、金钱与多种价值，提出如何安排、是否调整或放弃的建议，再回到月周日计划中协调。

## 私有输入

按需提供目的、日期范围、预算、节奏、近期安排与相关限制。地点、订单与同行信息仅在私有空间按必要性使用；不将证件号码作为默认规划输入。

## 记录字段

| 字段组 | 活动前与活动后内容 |
| --- | --- |
| 目的与价值 | 工作、学习、关系、体验、休息等，由使用者确定优先级 |
| 时间全成本 | 准备、交通、等待、活动、收尾与恢复；计划和实际分开 |
| 金钱与机会成本 | 预算、实际费用、取消成本及挤占的其他安排 |
| 条件与核实 | 交通、住宿、开放、预约、当地规则、来源及有效时间 |
| 候选与决定 | 参加、缩短、改期、调整路线或放弃；理由与授权状态 |
| 体验与复盘 | 主观体验、目的实现、负担、变化与下次调整 |

## 操作流程

1. 识别出行目的与近期安排，先问使用者重视哪些价值。
2. 计算时间全成本，与其他领域的明确承诺和资源比较。
3. 比较参加、压缩行程、换方式、推迟或不参加，说明获得与放弃的内容。
4. 选择参加后再细化路线、活动、休息与交通时间用途，不强行填满行程。
5. 对费用、开放、票务和适用规则核实当前来源；购买前确认日期、对象、费用与取消条件。
6. 出行后对照预期与实际复盘，修订后续安排与活动选择条件。

“高性价比”依据由使用者确认，不能只按学习产出或费用低来判断。休闲、文化体验与陪伴也可以是充分目的，详见[活动取舍方法](../../docs/activity-evaluation.md)。

## 可复制提示词

> 请在细排出行前，先结合我的目的、近期安排和时间精力预算比较参加、缩短、改期或放弃。说明总耗时、费用、机会成本及学习、工作、关系、休息或体验价值，权重由我确认。选定后再优化行程与可安全利用的交通时间；时效信息提供当前来源。只草拟，不代我订票付款；活动后按预期与实际复盘。

## 预期输出

是否参加及替代建议、资源和价值比较、经确认的行程候选、待核实项，以及活动后复盘。使用[活动评估模板](../../templates/activity-review.md)。

## 回退与复盘

前提未确认时先完成不依赖它的准备。已承诺或已付款的活动考虑取消成本与责任；超时订单先查状态，不重复下单。一次不佳体验不直接形成普遍取消规则。
