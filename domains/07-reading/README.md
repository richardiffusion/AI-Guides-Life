# 读书

结合近期阅读或自愿提供的历史书单、实际理解与可用时间，给出个性化选书、阅读时长安排和阅读方法建议，再随反馈调整。

## 私有输入

仓库外按需提供阅读目的、专业或工作中的相关问题、偏好、近期材料、历史书名及阅读状态。书名清单即可作为初步线索，不要求完整阅读史；不知道的进度与理解程度不能推断。

## 记录字段

| 字段组 | 内容与口径 |
| --- | --- |
| 材料 | 书名、作者或版本等必要书目信息，材料实际可得范围 |
| 历史状态 | 读过、部分、在读、待读、放弃或未知；是否主要读了摘要 |
| 目的与选择 | 兴趣、学习、工作应用、休闲等；推荐或选择理由 |
| 实际投入 | 阅读时段或时长、章节位置、专注与执行负担 |
| 理解与观点 | 核心问题、自述回忆、作者主张、解释和分歧 |
| 核实与应用 | 原文位置、待查出处、应用行动与反馈 |
| 方法反馈 | 精读、泛读、听读、回忆或笔记方式是否适合当前材料 |

私人读书记录不入仓库。仓库引用的通用书目信息不代表任何真实人物读过这些书。

## 操作流程

1. 整理历史与当前目的，区分熟悉主题、兴趣线索和真正掌握的证据。
2. 只按已提供信息形成暂定认识；读过某书不等于接受其观点或掌握其内容。
3. 根据目的、现有基础、偏好和资源给少量推荐，说明理由、前提和可能不适合之处。
4. 按实际可用时间和试读体验建议时长及频率，不设所有人统一目标。
5. 按材料与目标选择阅读方法：快速筛选、精读、回忆、讨论或应用，并说明取舍。
6. 将阅读纳入月周日计划，回看实际投入、理解与负担，允许调整和停读。

## 可复制提示词

> 请基于我自愿提供的近期阅读、历史书名和明确目的，先区分读过、部分阅读、摘要和未知，再给出推荐及理由。不要从书名单独推断我的能力、人格或全部偏好。根据实际时间和阅读反馈建议时长与方法，标明你实际看到的材料范围；不编造引文、页码、书籍信息或阅读进度。安排后用理解与应用反馈复盘。

## 预期输出

暂定阅读情况、候选推荐与适用性、时长和方法建议、周期安排及后续回顾问题。

## 回退与复盘

没有历史书单时可先用当前目的和试读反馈，不要求补齐全部过去。精力不足时缩减成一个观点、一个疑问或短时阅读；没有学习或职业产出也不自动否定休闲阅读价值。推荐书籍与版本信息需核实。
