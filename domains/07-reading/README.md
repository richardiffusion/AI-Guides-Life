# 读书

把选书、阅读、回忆、核实与应用连接起来，避免笔记越来越多却难以使用。

## 私有输入

在仓库外按需提供：阅读目的、现有理解、材料范围、可用精力与希望形成的产出。私人书单、批注、付费全文和账号历史不进入本仓库。

## 操作流程

1. 从一个想回答的问题出发选择材料，而非先堆积书单。
2. 明确材料实际可获得的范围：全文、节选、目录或仅书籍介绍。
3. 开始阅读前写下预测与问题，阅读后先自己回忆。
4. 再让 AI 帮忙整理结构、指出缺口并区分原文与推论。
5. 对关键论断回到原文核对，标明章节或可核对位置。
6. 选择一个应用、讨论问题或继续阅读的方向，允许停止不适合的材料。

## 可复制提示词

> 我会提供一段获准使用的材料和阅读目的。请先说明你实际看到的材料范围，再区分作者明确主张、你的解释和待核实内容。先用问题帮助我回忆，不直接代替我的全部思考。不要编造引文、页码、书中情节或我未报告的阅读进度；只有介绍时，不把输出称为全书总结。

## 预期输出

核心问题、材料范围、个人回忆后的整理、原文核对点、分歧与下一步。长篇原文与个人笔记保存在仓库外。

## 回退与复盘

精力或时间不足时，把完整笔记缩减为“一个观点、一个疑问、一个待查出处”。理解卡住时改用更具体的例子或先补背景。

复盘能否用自己的话说明观点、能否分清事实与推论、笔记能否支持后续使用。阅读数量和 AI 总结数量不直接代表理解质量。
