# 饮食

从低负担的菜品与大概份量记录开始，估计摄入范围；累积一段时间后分析饮食结构、可能缺项与调整方向，并在日常执行中复盘。

## 私有输入

按需提供菜名或食物描述、大概食用量、烹饪方式，以及预算、备餐条件和明确限制。身体信息仅在确实影响当前任务时于私有空间提供；不要求先精确称重每餐。

## 记录字段

| 字段组 | 必要或扩展字段 | 处理规则 |
| --- | --- | --- |
| 最低记录 | 日期、餐次或时段、菜品、实际吃了大概多少 | 可用碗、份、块等自然单位，注明估计 |
| 结构补充 | 主食、主要食材、饮品零食、烹调方式、共享份额及剩余 | 优先问最影响判断的缺口 |
| 估算依据 | 包装标签、匹配食品条目、份量换算、油酱等假设 | 保留来源与情境范围 |
| 营养估计 | 能量 kcal；蛋白质、脂肪、碳水 g | 条件足够才量化，不制造小数精度 |
| 可选成分 | 膳食纤维、钠及相关微量营养素 | 来源足够时才估，不用菜名猜出完整成分表 |
| 实际与体验 | 食用确认、饱足感、方便程度、费用、准备负担 | 采购或点单不等于吃下 |
| 已有补充 | 已用补充剂及其他强化来源 | 仅在相关且自愿时提供，避免重复累计 |
| 完整性 | 全日、部分餐次、漏记或未知 | 没记到不等于没吃 |

## 操作流程

1. 对模糊描述先给可确认的食物结构；仅追问会明显改变估算的份量、油酱或实际食用份额。
2. 优先使用匹配的标签或可信成分来源，按已知量换算。无法可靠估算时保留定性描述。
3. 有合理依据时给低、中、高情景范围和假设；这不是统计置信区间，也不是化验值。
4. 按有效记录汇总日、周及阶段情况，同时报告漏餐、漏天和不确定性；不把部分餐次汇总叫完整日摄入。
5. 区分“记录中未出现的食物”“可能摄入不足”“需专业评估的营养问题”，提出可执行的食物选择或采购备餐调整。
6. 将建议放入月周日安排，随后依据实际饮食与负担复盘，不为追求漂亮数字补造记录。

长期记录不能自动消除份量和菜品匹配的偏差。数据库与记录方法的依据见[来源说明](../../docs/health-sources.md)。

## 补充剂评估

综合建议应回答：现有证据是否支持讨论补充剂、还缺什么信息，以及是否应先从饮食调整或寻求专业评估开始。

粗略饮食记录不足以确认缺乏。需要结合实际适用的饮食结构、已有补充来源、个体限制和必要的专业判断，不能据几个菜名直接开品牌、剂量或长期服用方案。补充剂可能涉及过量与相互作用，相关依据见[NIH 来源](../../docs/health-sources.md)。

## 可复制提示词

> 请从我给出的菜品、做法和粗略食用量估计饮食结构；条件足够时给能量和营养素的情景范围、来源及主要假设，无法量化就明说。累计阶段分析时说明覆盖、漏记与系统偏差，区分未记录、可能不足和已确认问题。综合建议包括吃了什么、哪些类别记录不足、食物调整及是否值得讨论补充剂；不直接诊断缺乏或给补充剂处方。再提出每日可执行动作与复查方式。

## 预期输出

每餐估计及依据、日与阶段汇总、饮食结构与证据缺口、补充剂讨论状态、采购备餐建议及后续复盘。使用[阶段总结模板](../../templates/period-review.md)。

## 回退与复盘

不确定性太大时简化为食物类别和份量描述，不用精确数字掩盖缺口。补记修正后重算派生汇总，不重复相加。出现不适或存在明确限制时先尊重限制并获得适当判断。
