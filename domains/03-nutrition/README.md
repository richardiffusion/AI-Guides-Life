# 饮食

把菜单选择、采购、储存、备餐与外食安排成可执行流程。

本指南不提供统一能量目标、减重处方或疾病饮食方案。

## 私有输入

在仓库外按需提供：预算范围、备餐条件、可用时间、食材可得性、明确的饮食限制与过敏相关边界。身体指标、医疗记录和订单历史不是默认必需输入。

## 操作流程

1. 确认本次要解决的是选择困难、采购、备餐还是外食协调。
2. 先列硬性限制与可用条件，再形成少量备选餐食。
3. 将备选方案拆为采购、处理、储存和食用步骤。
4. 用已有食材与可替代项减少采购复杂度；食用安全仍需按可靠指引判断。
5. 为无暇准备或食材不可得的情况准备可行备选。
6. 复盘准备负担、预算、浪费和适配性，不只评价菜单是否“理想”。

## 可复制提示词

> 请依据我提供的预算、时间、设备、食材条件与明确限制，草拟菜单选择流程和采购清单。先指出会影响可执行性的未知项；硬性限制未确认前，不输出看似可直接执行的最终菜单。给每个方案说明准备成本、替代条件及需要核实的成分信息。不要自行推断疾病或制定能量处方，不代我下单。

## 预期输出

备选餐食、所需食材、采购与准备步骤、替代方案、待核实成分和费用项。涉及事实时使用[信息核实表](../../templates/source-check.md)。

## 回退与复盘

食材缺货或外食条件变化时，按限制重新筛选备选，不直接替换成未经确认的成分。出现不适时停止自行调整并寻求适当判断。

采购完成、餐食准备完成和实际食用分别记录；没有食用反馈时不能推算摄入。个人记录仅在仓库外保存。
