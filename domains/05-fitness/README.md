# 健身

先充分了解与当前运动目标相关的情况，积累训练与恢复记录，结合已有运动手表数据，形成分类型的阶段建议，再安排到月周日。

“充分了解”不等于收集所有个人资料；关键信息不够时明确缺口，不直接给出具体负荷。

## 私有输入

按需提供目标、经验、现有运动方式和习惯、可用时间与器材、相关限制、训练记录和获授权的设备汇总。身体状况仅在必要范围内提供，未知不补全；原始健康或训练资料不进入仓库。

## 记录字段

| 字段组 | 具体内容 | 用途 |
| --- | --- | --- |
| 初始情况 | 目标、经验、偏好、习惯、场地器材、时间与限制 | 区分建议适用性 |
| 力量及增肌训练 | 动作、实际组次、负重、休息、动作反馈、主观强度 | 看动作与进阶的实际基础 |
| 有氧及专项 | 活动方式、时长、距离或节奏、可用强度信息 | 比较同类活动，识别执行负担 |
| 训练前后 | 准备、当日精力、疲劳、不适与恢复感受 | 判断安排是否可执行及需否暂停 |
| 设备数据 | 实际可得的活动、心率、训练等估计，佩戴和缺失 | 辅助观察，保留算法口径 |
| 计划与实际 | 原安排、完成内容、变化、原因及证据 | 避免将计划当完成 |
| 长期反馈 | 相同口径的表现变化、执行一致性与其他情境 | 形成阶段建议 |

肌肉增长与力量提升可以共享抗阻训练内容，但目标和评估不同，不重复计为两次活动。器械或负重口径变化需标明。设备没有记录不能直接判定没练，设备消耗也不是精确可抵扣的饮食预算。

## 操作流程

1. 澄清目标与相关情况，标明需要教练或医疗专业判断的限制。
2. 整理已有历史，或约定新的观察范围；同时核对设备覆盖与手动记录。
3. 将抗阻训练中的增肌、力量目标，有氧、专项及活动恢复分开分析。
4. 依据实际经验、完成情况、偏好和恢复，解释候选训练方式及适用条件。
5. 需要具体技术、动作教学或负荷进阶时引用额外适用依据，必要时获得合适指导；不从手表分数直接生成训练处方。
6. 由使用者选定月度方向、周训练安排和每日动作，统筹饮食、睡眠、工作与出行。
7. 按阶段反馈保留、修订或停止建议，避免因漏练惩罚性补量。

群体活动指南可提供类别参考，不能代替个体技术和适用性判断，见[运动来源](../../docs/health-sources.md)。

## 可复制提示词

> 请先了解与我的目标相关的经验、现有运动习惯、器材、时间和限制，再检查一段时间训练与手表数据的覆盖。区分增肌、力量、有氧和专项需求，给出有理由的候选方式及需要补充的技术依据。结合睡眠、饮食和恢复形成综合建议并落实到月周日；不补造负荷或完成记录，不用设备分数代替专业判断，不自行制定康复方案。

## 预期输出

现有运动情况、数据质量、分类型建议、技术或专业指导需求、周期安排、替代选择和复查条件。使用[阶段总结模板](../../templates/period-review.md)。

## 回退与复盘

数据不足时先整理适用约束和可观察的低风险流程。时间或恢复条件不合适时缩减或取消；疼痛、不适或其他异常时停止受影响动作并获得适当判断。复盘具体原因，不把所有问题归结为意志力。
