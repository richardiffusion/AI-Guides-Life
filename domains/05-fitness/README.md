# 健身

把明确的训练目标与限制转成可执行的训练安排，并为恢复与变化留出空间。

本指南不替代训练技术指导、医疗评估或康复方案，不预设统一训练频率、重量或强度。

## 私有输入

在仓库外按需提供：目标类型、经验范围、可用场地与器材、时间限制、已明确的动作限制与专业建议。不要求上传身体照片、训练原始日志或伤病资料。

## 操作流程

1. 确认目标和已知限制；关键信息不足时先整理问题，不直接开出详细负荷。
2. 在使用者可执行的活动中选择主安排，说明准备、训练和收尾环节。
3. 给出器材不可用、时间不足或恢复状态不适合时的替代与取消条件。
4. 由使用者确认安排，技术不明确时先获得合适指导。
5. 将计划负荷与实际完成分开，保留“不确定”和“未报告”。
6. 根据实际反馈审查安排是否合适，不因单次未完成惩罚性加量。

## 可复制提示词

> 请帮我组织训练计划的执行流程。先复述目标、已知经验、器材与限制，列出阻止安全具体化的未知项。只在信息足够且符合明确限制时整理候选安排，附最低版本、取消条件和需要专业指导的部分。不要编造完成记录、动作负荷或身体状态，不自行制定康复方案。

## 预期输出

目标、训练前确认项、候选活动、准备与收尾、替代选择、停止条件及私有反馈字段。

## 回退与复盘

时间不足时按原先约定缩减或取消，不把完整训练压缩到不合适的时段。出现疼痛、不适或其他异常时停止受影响动作并获得适当判断。

复盘执行一致性、主观体验、恢复和负担；仅在证据支持时改变一个因素。方法尝试可用[单变量模板](../../templates/experiment.md)，不用于自行试验治疗。
