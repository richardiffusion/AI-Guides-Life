# 通勤

结合一段时间的工作、生活约束与实际移动记录，回答如何通勤、如何缩短总成本，以及可用的通勤时间适合做什么。

## 私有输入

在仓库外用区域和路线代号描述必要的起终点、到达边界、交通方式、预算、习惯与当前安排。实际路线服务需要精确位置时，另按授权提供，不要求完整轨迹或雇主信息。

## 记录字段

| 字段组 | 内容 |
| --- | --- |
| 背景约束 | 工作生活中的时间边界、出行频率、预算、可用方式与必要限制 |
| 路线与时段 | 方向、路线代号、方式、适用日类型、出发与到达时间 |
| 分段耗时 | 准备、步行、等待、乘坐、换乘和后续衔接 |
| 实际体验 | 费用、拥挤、舒适、疲劳、延误及原因 |
| 可用条件 | 是否驾驶或骑行、站立或坐下、噪声、网络及需要的注意力 |
| 时间利用 | 休息、听读或其他活动是否合适，实际体验与负担 |
| 信息质量 | 实际记录或估计、漏记、来源与实时核实时间 |

单程、往返及不同方向分开；合并办事的行程注明分配口径，不把全部耗时误计为通勤。

## 操作流程

1. 覆盖相关方向、日类型和时段，了解常见与波动较大的情况。
2. 区分可减少的等待、绕行、准备和换乘成本，以及暂时不可调整的条件。
3. 比较路线、方式、错峰或其他安排的候选变化，同时考虑费用、精力和约束。
4. 关于缩短时长的建议给出依据、估计范围和试行条件，不保证节省。
5. 根据注意力条件讨论休息、听读、复习等选择；驾驶骑行等情境不安排分散注意的互动。
6. 将方案纳入周期计划，观察实际是否节时、是否增加负担，再复盘。

通勤时间不必全部用于生产或学习，休息也是由使用者选择的用途。

## 可复制提示词

> 请结合我提供的一段时间通勤记录与必要工作生活约束，分析路线、方式、耗时组成、波动和负担。给缩短通勤时长的候选方案及节省依据，实时信息标明核实时间。再按交通方式和注意力条件建议时间用途，包括休息；不默认每段时间都要学习，不建议驾驶或骑行时分散注意的操作。

## 预期输出

通勤现状、时间成本分解、方式与路线比较、缩短时长的候选变化、安全可行的时间用途及复查条件。

## 回退与复盘

路线和班次变化时复核备选，不沿用未经验证的旧结论。影响迟到沟通、购票或共享位置的动作需要相应授权。复盘真实节省和代价，不把一次顺畅推广为稳定保证。
