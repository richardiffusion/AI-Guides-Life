# 通勤

比较可用路线，安排出发前准备，并在延误时快速启用备选。

## 私有输入

在仓库外按需提供：出发与到达区域的抽象代号、到达边界、交通方式、费用范围、可接受步行或换乘条件。只有实际路线服务确有需要时，才在获得授权后提供必要位置。

## 操作流程

1. 先用代号整理路线条件，不收集固定住址与工作单位。
2. 查询适用日期和方向的班次、运营、道路或停车信息。
3. 比较交通耗时、步行、等待、换乘、费用与不确定性。
4. 在到达约束之外计算准备和切换成本，说明缓冲依据。
5. 确定主路线、备选路线和切换触发条件。
6. 出发前复核变化；无法实时核实时标明信息时间与缺口。

## 可复制提示词

> 请比较我提供的通勤候选方案，分别列出准备、步行、等待、乘坐、换乘、费用和不确定性。交通信息须标明来源与核实时间，查不到实时状态时明确说明。给主方案、备选和切换条件，不编造班次或保证准点。路线查询使用最少位置数据，不自动预订、付款或共享位置。

## 预期输出

可比较的路线表、待核实信息、出发准备清单、备选触发条件，以及已授权范围内的后续动作。

## 回退与复盘

主要路线不可用时重新检查备选，不假设旧备选仍然有效。若需要告知他人迟到，先草拟信息；发送须有相应授权。

移动中的互动必须适合当前交通方式；驾驶、骑行或其他需要持续注意的情境，不安排分散注意的阅读或复杂对话。

复盘实际延误类型和准备成本，不保留可识别个体的轨迹到本仓库。时效事实可用[信息核实表](../../templates/source-check.md)。
